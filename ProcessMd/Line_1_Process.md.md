# OP20: 피팅 체결 및 AI 비전 검사 (무인 공정) 시나리오

## 1. 개요
A라인의 핵심 무인 자동화 공정(EQ-A01)입니다. C# 기반의 가상 PLC 로직과 라즈베리 파이 카메라 기반의 형상 인식 AI가 결합하여, 실제 하드웨어 없이도 설비의 제어와 품질 검사를 시뮬레이션합니다.

## 2. 설비 동작 및 데이터 생성 시나리오
물리적 액추에이터가 없는 환경을 극복하기 위해 하이브리드(수동 세팅 + 자동 제어) 방식을 채택합니다.
* **가상 이송 및 체결:** OP10에서 투입된 제품이 EQ-A01에 도착하면(타이머 시뮬레이션), C# 가상 설비의 상태 레지스터가 '운전 중(1)'으로 변경됩니다. 
* **환경 데이터 발생:** 체결 시퀀스(약 12초) 동안 가상의 공압 데이터와 진동 데이터(MPU6050 모사)가 생성됩니다. 특정 확률로 공압 저하 및 진동 상승 에러를 의도적으로 발생시켜 예지보전 시나리오의 기반 데이터를 만듭니다.

## 3. AI 비전 검사 트리거 및 판정
라즈베리 파이 카메라 모듈 v2를 활용한 엣지(Edge) 비전 검사입니다.
* **촬영 지시:** 체결 완료 시점에 상위 시스템 또는 가상 PLC가 카메라로 촬영 트리거를 전송합니다. (테스트 시 카메라 앞에 부품이나 샘플 이미지를 수동으로 세팅합니다.)
* **형상 인식 및 분류:** YOLOv11(검출) 및 Swin Transformer(분류) 모델이 이미지를 분석하여 부품의 체결 상태(완전체결, 부분체결, 미체결, 오류체결) 4단계 중 하나로 즉각 판정합니다[cite: 1].
* **결과 전송:** 판정 결과와 신뢰도(Confidence), 이미지 경로가 Serial 번호와 함께 MES API로 전송됩니다[cite: 1].

## 4. 물리적 예외 처리 (자동 배출 로직)
검사 결과에 따른 Modbus TCP 기반의 설비 제어 피드백 루프입니다.
* **불량(NG) 수신:** MES 시스템이 AI 판정 결과를 바탕으로 불량 레코드를 생성합니다 (`detectedBy: "AI-Vision"`)[cite: 1].
* **배출 제어:** MES는 즉시 NModbus를 통해 가상 설비의 배출 코일(Reject Cylinder)에 `ON` 제어 신호를 보냅니다.
* **로그 시각화:** 실물 배출 실린더가 없으므로, React 대시보드 및 콘솔 화면에 해당 Serial 번호의 자동 배출 처리가 완료되었음이 실시간 알람으로 시각화됩니다.
